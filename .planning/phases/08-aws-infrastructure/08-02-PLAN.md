<task type="auto">
  <name>Task 1: Write scripts/setup-aws-infra.sh</name>
  <files>scripts/setup-aws-infra.sh</files>
  <action>
    Create `scripts/setup-aws-infra.sh` following the established project pattern (`set -euo pipefail`, check-then-create, named constants, `--profile kiss` on every AWS CLI call, explicit `--region us-east-1` on every call).

    The script must:
    - Be idempotent — safe to re-run without creating duplicate resources
    - Follow the 5-step order: (1) key pair, (2) security group + rules, (3) AMI lookup, (4) EC2 instance, (5) Elastic IP
    - Print the Elastic IP at the end (used by Phases 10 and 11)
    - Tag all resources with `Key=Name,Value=kiss-server` for idempotency checks on re-run

    **Named constants (top of script):**
    ```bash
    REGION="us-east-1"
    KEY_NAME="kiss-server"
    SG_NAME="kiss-server-sg"
    INSTANCE_NAME="kiss-server"
    PROFILE="kiss"
    ```

    **Step 1 — Key pair (import ~/.ssh/id_ed25519.pub):**
    - Check: `aws ec2 describe-key-pairs --key-names "$KEY_NAME" --profile "$PROFILE" --region "$REGION" --query 'KeyPairs[0].KeyName' --output text 2>/dev/null || echo ""`
    - If result equals KEY_NAME: print "already exists, skipping"
    - Else: `aws ec2 import-key-pair --key-name "$KEY_NAME" --public-key-material fileb://~/.ssh/id_ed25519.pub --profile "$PROFILE" --region "$REGION"`

    **Step 2 — Security Group + rules:**
    - Check: `aws ec2 describe-security-groups --filters "Name=group-name,Values=$SG_NAME" --query 'SecurityGroups[0].GroupId' --output text --profile "$PROFILE" --region "$REGION" 2>/dev/null || echo ""`
    - If result is empty or "None": create SG, then immediately authorize both rules inside the same if-block (guards against `InvalidPermission.Duplicate` on re-run)
    - Create: `aws ec2 create-security-group --group-name "$SG_NAME" --description "kiss-server web and SSH access" --profile "$PROFILE" --region "$REGION" --query 'GroupId' --output text`
    - Authorize port 22: `--protocol tcp --port 22 --cidr 0.0.0.0/0`
    - Authorize port 80: `--protocol tcp --port 80 --cidr 0.0.0.0/0`
    - Else: print "already exists" and read existing SG_ID from describe output

    **Step 3 — AMI lookup via SSM (never hardcode AMI ID):**
    ```bash
    AMI_ID=$(aws ssm get-parameter \
      --name /aws/service/ami-amazon-linux-latest/al2023-ami-kernel-default-x86_64 \
      --profile "$PROFILE" \
      --region "$REGION" \
      --query 'Parameter.Value' --output text)
    echo "Using AMI: $AMI_ID"
    ```

    **Step 4 — EC2 instance:**
    - Check: `aws ec2 describe-instances --filters "Name=tag:Name,Values=$INSTANCE_NAME" "Name=instance-state-name,Values=running,stopped,pending" --query 'Reservations[0].Instances[0].InstanceId' --output text --profile "$PROFILE" --region "$REGION" 2>/dev/null || echo ""`
    - If non-empty and not "None": print "already exists" and use existing INSTANCE_ID
    - Else: launch with:
      - `--image-id "$AMI_ID"`
      - `--instance-type t3.micro`
      - `--key-name "$KEY_NAME"`
      - `--security-group-ids "$SG_ID"`
      - `--count 1`
      - `--credit-specification CpuCredits=standard` (prevents unexpected burst charges)
      - `--tag-specifications "ResourceType=instance,Tags=[{Key=Name,Value=$INSTANCE_NAME}]"`
      - `--profile "$PROFILE" --region "$REGION"`
      - `--query 'Instances[0].InstanceId' --output text`
    - After launch: `aws ec2 wait instance-running --instance-ids "$INSTANCE_ID" --profile "$PROFILE" --region "$REGION"`

    **Step 5 — Elastic IP:**
    - Check: `aws ec2 describe-addresses --filters "Name=tag:Name,Values=$INSTANCE_NAME" --query 'Addresses[0].AllocationId' --output text --profile "$PROFILE" --region "$REGION" 2>/dev/null || echo ""`
    - If empty or "None": allocate new EIP (`--domain vpc`), tag it immediately with `Key=Name,Value=$INSTANCE_NAME`
    - Associate: `aws ec2 associate-address --instance-id "$INSTANCE_ID" --allocation-id "$ALLOC_ID" --profile "$PROFILE" --region "$REGION"` (safe to re-run — reassociating to same instance is a no-op)
    - Retrieve public IP: `aws ec2 describe-addresses --allocation-ids "$ALLOC_ID" --query 'Addresses[0].PublicIp' --output text --profile "$PROFILE" --region "$REGION"`
    - Print: `echo "Elastic IP: $ELASTIC_IP"`

    Make the script executable:
    ```bash
    chmod +x scripts/setup-aws-infra.sh
    ```
