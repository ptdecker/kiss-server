  <action>Human must configure AWS credentials — Claude cannot supply access keys.</action>
  <verify>
    <automated>aws sts get-caller-identity --profile kiss</automated>
  </verify>
  <done>`aws sts get-caller-identity --profile kiss` returns AccountId, UserId, and Arn without error</done>
  <what-to-do>
    Configure a named AWS CLI profile called `kiss` with your AWS access key and secret.

    Run:
    ```bash
    aws configure --profile kiss
    ```

    When prompted:
    - AWS Access Key ID: [your access key from IAM console]
    - AWS Secret Access Key: [your secret key from IAM console]
    - Default region name: us-east-1
    - Default output format: text

    If you don't have an IAM access key yet:
    1. Log into AWS Console → IAM → Users → your user
    2. Security credentials tab → Create access key
    3. Choose "Command Line Interface (CLI)" use case
    4. Copy the Access Key ID and Secret Access Key

    After configuring, verify credentials work:
    ```bash
    aws sts get-caller-identity --profile kiss
    ```

    Expected: JSON output showing your AWS AccountId, UserId, and Arn — no error.
  </what-to-do>
  <resume-signal>Type "configured" once `aws sts get-caller-identity --profile kiss` returns your account details</resume-signal>
</task>

<task type="auto">
  <name>Task 3: Verify default VPC exists in us-east-1</name>
  <files></files>
  <action>
    Confirm the default VPC exists in us-east-1 before provisioning. The setup script uses it implicitly (no --subnet-id); if it was deleted, run-instances will fail.

    ```bash
    aws ec2 describe-vpcs \
      --filters Name=isDefault,Values=true \
      --query 'Vpcs[0].VpcId' \
      --output text \
      --region us-east-1 \
      --profile kiss
    ```

    Expected output: a VPC ID like `vpc-xxxxxxxx`.

    If output is `None` or empty: the default VPC was deleted. In that case, create it:
    ```bash
    aws ec2 create-default-vpc --region us-east-1 --profile kiss
    ```

    Then re-run the describe command to confirm the VPC ID.
  </action>
  <verify>
    <automated>aws ec2 describe-vpcs --filters Name=isDefault,Values=true --query 'Vpcs[0].VpcId' --output text --region us-east-1 --profile kiss | grep '^vpc-'</automated>
  </verify>
  <done>Default VPC ID (vpc-xxxxxxxx) returned for us-east-1</done>
</task>
