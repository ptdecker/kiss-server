Create two files:

**rust-toolchain.toml** (repo root):
```toml
# Source: https://rust-lang.github.io/rustup/overrides.html
[toolchain]
channel = "1.93.1"
components = ["rustfmt", "clippy"]
targets = ["x86_64-unknown-linux-gnu"]
```

**scripts/ci.sh** (create `scripts/` directory first):
```bash
#!/usr/bin/env bash
set -euo pipefail

cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo build --locked
cargo test --locked
```

After writing scripts/ci.sh, run: `chmod +x scripts/ci.sh`

Verify locally: `./scripts/ci.sh` — must exit 0. If it fails, fix the underlying Rust issue before proceeding (do not weaken the script).

Note: `--locked` applies to `cargo build` and `cargo test` because `Cargo.lock` is committed. `cargo fmt --check` and `cargo clippy` do not accept `--locked` in the same way — they are left without it per the research.

Actually, per the research open question resolution: apply `--locked` to `cargo clippy` as well for consistency. The full script:
```bash
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo build --locked
cargo test --locked
```

<task type="auto">
  <name>Task 2: Create ci.yml and delete rust.yml</name>
  <files>.github/workflows/ci.yml, .github/workflows/rust.yml</files>
  <action>
Create `.github/workflows/ci.yml`:
```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

env:
  CARGO_TERM_COLOR: always

jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@master
      - uses: Swatinem/rust-cache@v2
        with:
          cache-on-failure: "true"
      - name: Run CI
        run: ./scripts/ci.sh
```

Then delete `.github/workflows/rust.yml`:
```bash
git rm .github/workflows/rust.yml
```

Critical checks:
- Job key is `ci:` (not `build:`) — Phase 7 branch protection depends on this name
- `dtolnay/rust-toolchain@master` has NO `toolchain:` input — it reads rust-toolchain.toml automatically
- `./scripts/ci.sh` is the only `run:` step — no inline cargo commands
- `actions/checkout@v4` (not v3 from old rust.yml)
  </action>
