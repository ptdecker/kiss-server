  <files>scripts/install-kiss-server.sh</files>
  <action>
    Create `scripts/install-kiss-server.sh` following the exact `scripts/setup-aws-infra.sh` pattern:
    `#!/usr/bin/env bash`, `set -euo pipefail`, named constants section at top, check-then-create
    idempotency for every step, echo progress to stdout.

    Named constants (place at top after set -euo pipefail):
    ```
    CLONE_DIR="/opt/ptodd"
    REPO_URL="https://github.com/ptdecker/kiss-server.git"
    BINARY_SRC="$CLONE_DIR/target/release/ptodd"
    BINARY_DEST="/usr/local/bin/kiss-server"
    KISS_USER="kiss-server"
    SERVICE_FILE="/etc/systemd/system/kiss-server.service"
    WEBROOT="/var/www/ptodd.org"
    ```

    Steps in order (each idempotent):

    1. SWAP FILE PRECAUTION (per critical finding: t3.micro has no swap, OOM risk):
       ```bash
       if ! swapon --show | grep -q /swapfile; then
         echo "  Creating 512MB swap file..."
         sudo dd if=/dev/zero of=/swapfile bs=1M count=512 status=progress
         sudo chmod 600 /swapfile
         sudo mkswap /swapfile
         sudo swapon /swapfile
         echo "  Swap active."
       else
         echo "  Swap file already active, skipping."
       fi
       ```

    2. INSTALL GIT (per D-03):
       ```bash
       if command -v git &>/dev/null; then
         echo "  git already installed, skipping."
       else
         echo "  Installing git..."
         sudo dnf install -y git
       fi
       ```

    3. INSTALL RUSTUP/CARGO (per D-02, D-03):
       ```bash
       if command -v cargo &>/dev/null; then
         echo "  Rust toolchain already installed, skipping."
       else
         echo "  Installing rustup (stable)..."
         curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --default-toolchain stable
       fi
       source "$HOME/.cargo/env"
       ```

    4. CLONE OR UPDATE REPO (per D-01, D-02):
       ```bash
       if [ -d "$CLONE_DIR/.git" ]; then
         echo "  Repo already cloned, pulling latest..."
         git -C "$CLONE_DIR" pull
       else
         echo "  Cloning repo to $CLONE_DIR..."
         sudo git clone "$REPO_URL" "$CLONE_DIR"
         sudo chown -R ec2-user:ec2-user "$CLONE_DIR"
       fi
       ```

    5. BUILD RELEASE BINARY (per D-01):
       Build as ec2-user (no sudo) to keep toolchain in PATH:
       ```bash
       echo "  Building release binary (this may take a few minutes)..."
       cargo build --release --manifest-path "$CLONE_DIR/Cargo.toml"
       ```

    6. INSTALL BINARY (rename ptodd → kiss-server per critical finding #2):
       ```bash
       echo "  Installing binary to $BINARY_DEST..."
       sudo cp "$BINARY_SRC" "$BINARY_DEST"
       sudo chmod +x "$BINARY_DEST"
       ```

    7. CREATE SERVICE USER (per D-08):
       ```bash
       if id "$KISS_USER" &>/dev/null; then
         echo "  User '$KISS_USER' already exists, skipping."
       else
         echo "  Creating system user '$KISS_USER'..."
         sudo useradd --system --no-create-home --shell /sbin/nologin "$KISS_USER"
       fi
       ```

    8. WRITE SYSTEMD UNIT (per D-08, DEPLOY-02):
       Write to $SERVICE_FILE only if it does not exist or content differs.
       Use a heredoc to write the exact unit:
       ```
       [Unit]
       Description=kiss-server static file server
       After=network.target

       [Service]
       Type=simple
       User=kiss-server
       ExecStart=/usr/local/bin/kiss-server --root /var/www/ptodd.org --port 8080
       Restart=on-failure
       RestartSec=5
       StandardOutput=journal
       StandardError=journal

       [Install]
       WantedBy=multi-user.target
       ```
       After writing: `sudo systemctl daemon-reload`

    9. ENABLE AND START SERVICE (per DEPLOY-02):
       ```bash
       sudo systemctl enable kiss-server
       sudo systemctl restart kiss-server
       ```

    End with: `echo "install-kiss-server.sh complete."`

    After writing the file: `chmod +x scripts/install-kiss-server.sh` and run
    `bash -n scripts/install-kiss-server.sh` to verify shell syntax.

    --- scripts/setup-iptables.sh ---
    (per D-07, DEPLOY-03; critical finding #3: INPUT chain must also ACCEPT ports 80 and 8080)

    Constants:
    ```
    IPTABLES_SERVICE="iptables"
    ```

    Steps:
    1. Install iptables-services (idempotent via dnf):
       ```bash
       if rpm -q iptables-services &>/dev/null; then
         echo "  iptables-services already installed, skipping."
       else
         echo "  Installing iptables-services..."
         sudo dnf install -y iptables-services
       fi
       ```

    2. Start and enable iptables service (MUST precede `service iptables save` per critical pitfall #2):
       ```bash
       echo "  Starting and enabling iptables service..."
       sudo systemctl start iptables
       sudo systemctl enable iptables
       ```

    3. Add PREROUTING REDIRECT rule (idempotent via iptables -C check):
       ```bash
       if sudo iptables -t nat -C PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080 2>/dev/null; then
         echo "  PREROUTING REDIRECT rule already exists, skipping."
       else
         echo "  Adding PREROUTING REDIRECT rule (80 -> 8080)..."
         sudo iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080
       fi
       ```

    4. Add INPUT ACCEPT for port 80 (idempotent via iptables -C check):
       ```bash
       if sudo iptables -C INPUT -p tcp --dport 80 -j ACCEPT 2>/dev/null; then
         echo "  INPUT ACCEPT port 80 already exists, skipping."
       else
         echo "  Adding INPUT ACCEPT rule for port 80..."
         sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
       fi
       ```

    5. Add INPUT ACCEPT for port 8080 (critical finding #3 — redirected traffic traverses INPUT):
       ```bash
       if sudo iptables -C INPUT -p tcp --dport 8080 -j ACCEPT 2>/dev/null; then
         echo "  INPUT ACCEPT port 8080 already exists, skipping."
       else
         echo "  Adding INPUT ACCEPT rule for port 8080..."
         sudo iptables -A INPUT -p tcp --dport 8080 -j ACCEPT
       fi
       ```

    6. Save rules for persistence across reboots (per D-07):
       ```bash
       echo "  Saving iptables rules..."
       sudo service iptables save
       ```

    End with: `echo "setup-iptables.sh complete."`

    After writing both files: `chmod +x` each, run `bash -n` on each to verify syntax.
