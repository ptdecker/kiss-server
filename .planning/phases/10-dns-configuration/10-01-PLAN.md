**Header comment block:**

```
# verify-dns.sh
# Smoke test for DNS configuration of ptodd.org.
# Checks A record, CNAME resolution, and HTTP content for both
# ptodd.org and www.ptodd.org.
#
# Usage: bash scripts/verify-dns.sh
# Requirements: dig, curl (both present on macOS and Amazon Linux 2023)
# Run from: Developer machine (not EC2)
```

**Named constants (per D-02, D-03):**
```
ELASTIC_IP="54.83.192.65"
DOMAIN="ptodd.org"
WWW_DOMAIN="www.ptodd.org"
FAILURES=0
```

**Step 1 -- A record check (DNS-01):**
Use `dig +short "$DOMAIN" A` to get resolved IP. Compare string equality against `$ELASTIC_IP`. Print `PASS: ptodd.org resolves to 54.83.192.65` or `FAIL: ptodd.org resolves to 'X' (expected '54.83.192.65')`. Increment FAILURES on mismatch.

**Step 2 -- www resolution check (DNS-02):**
Use `dig +short "$WWW_DOMAIN" A` to get resolved IP (follows CNAME chain automatically). Compare string equality against `$ELASTIC_IP`. Print PASS/FAIL. Increment FAILURES on mismatch.

**Step 3 -- HTTP content check for ptodd.org (DNS-03 part 1):**
Use `curl -fs --max-time 10 "http://$DOMAIN/" | grep -q "Hello World"`. Print PASS/FAIL. Increment FAILURES on failure. Wrap in if/else (do NOT rely on set -e for this -- the grep exit code must be caught).

**Step 4 -- HTTP content check for www.ptodd.org (DNS-03 part 2):**
Same as Step 3 but for `$WWW_DOMAIN`.

**Summary block:**
Print blank line, then: if FAILURES is 0, print "All checks passed. DNS configuration is correct." and exit 0. Otherwise print "$FAILURES check(s) failed." followed by "If DNS was just changed, wait up to 1 hour for propagation and re-run." and exit 1.

**Important implementation details:**
- Use `echo "==> Step N: ..."` headers matching the project script pattern
- Each step's pass/fail line indented with two spaces: `echo "  PASS: ..."` / `echo "  FAIL: ..."`
- The curl steps must use `if curl ... | grep -q ...; then` pattern, NOT bare commands that would trigger set -e on failure
- Do NOT add a propagation wait loop (per research recommendation) -- just print the "wait and re-run" message on failure
- Make the file executable: chmod +x scripts/verify-dns.sh
