The developer must configure two DNS records in the GoDaddy web UI. These steps cannot be automated (per D-01).

**Pre-flight:** The current DNS state (as of 2026-03-24):
- `@` A record currently points to `74.220.199.6` (stale -- must be changed)
- `www` CNAME does not exist (must be created)
- `www` may have an A record pointing to `74.220.199.6` -- if so, DELETE it before creating the CNAME

**Step-by-step GoDaddy UI instructions:**

1. Open https://godaddy.com and log in
2. Navigate: My Products -> Domains -> find ptodd.org -> click "DNS" (or "Manage DNS")
3. **Update A record (DNS-01, per D-02):**
   - Find the existing A record where Host = `@` and Value = `74.220.199.6`
   - Click the pencil/edit icon on that row
   - IMPORTANT: EDIT the existing record -- do NOT add a new one (adding creates round-robin with two IPs)
   - Change Value to: `54.83.192.65`
   - Leave TTL at default (600 seconds is fine)
   - Save
4. **Check for existing www records:**
   - Look for any existing record with Host = `www`
   - If a `www` A record exists (pointing to `74.220.199.6`), DELETE it first
   - If a `www` CNAME already exists pointing to `@`, no action needed
5. **Create CNAME record (DNS-02, per D-03):**
   - Click "Add" or "Add Record"
   - Type: CNAME
   - Host/Name: `www`
   - Value/Points to: `@`
   - TTL: default (600 seconds)
   - Save

**After saving:** DNS propagation may take up to 1 hour. Typically completes within minutes for GoDaddy zones.
