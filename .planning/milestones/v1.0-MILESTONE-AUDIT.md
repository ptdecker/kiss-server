## Tech Debt (Non-Blocking)

### Date header on error paths (HTTP-03)
- **Phase:** 02-response-and-http-compliance
- **Detail:** `send_error_response` adds Date only if `DateTime::now()` returns `Ok`. If system clock fails, header omitted. RFC 9110 requires Date on all responses.
- **Risk:** None in practice — `SystemTime::now()` does not fail on any real server.
- **Action:** Acceptable at v1.0. Could add static fallback timestamp for v2.

### HEAD / falls through to StaticFileHandler
- **Phase:** 03-handler-context-and-router
- **Detail:** `GET /` route only matches GET. `HEAD /` misses route, falls through to StaticFileHandler → 404 (no file at root path).
- **Risk:** `HEAD /` returns 404 rather than 200 with headers. Technically correct HTTP behavior.
- **Action:** Register HEAD handler explicitly if needed. Acceptable at v1.0.

### pct_decode dead code
- **Phase:** 04-url-path-safety
- **Detail:** `pct_decode` helper in `url/mod.rs` suppressed with `#[allow(dead_code)]`; `from_utf8` import silenced transitively.
- **Risk:** None functional.
- **Action:** Remove or use in v2.
