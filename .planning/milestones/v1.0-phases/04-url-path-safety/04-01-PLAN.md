<objective>
Add URL path safety to the Url type and Router.

Four methods are added to Url in src/url/mod.rs: path() (strips query string), query() (returns
raw query string), decoded_path() (percent-decodes the path, returns Result<String>), and is_safe()
(checks decoded components for ..  — usable standalone in tests). The Router's dispatch() gains a
safety guard at its entry point that calls decoded_path() once, rejects invalid sequences and dotdot
components with 404, and then routes on the decoded path string (PATH-01). The #![allow(unused)]
lint suppressor is removed from url/mod.rs once the methods are consumed by the Router.

PATH-03 (canonicalize + starts_with(root) check) is explicitly deferred to Phase 5's
StaticFileHandler — it requires a configured server root path that does not exist in this phase.
Phase 5 MUST implement this as the third traversal defense layer.

Purpose: Without percent-decoding, routes only match literal raw paths. Without the dotdot guard,
handlers can receive traversal-attempt paths — the filesystem check in Phase 5 would be the only
defense. Defense-in-depth requires the structural check here, at the router layer.

Output:
- src/url/mod.rs — four new methods on Url, #![allow(unused)] removed, new unit tests
- src/server/router.rs — dispatch() updated with safety guard and decoded-path routing, new tests

use super::{
    context::Context, handler::Handler, request::RequestMethod, response::Response, Result,
};

pub struct Router {
    routes: Vec<(RequestMethod, String, Box<dyn Handler>)>,
}

impl Router {
    pub fn dispatch(&self, ctx: &mut Context) -> Result<()> {
        let method = &ctx.request.method;
        let path = ctx.request.target.to_string();  // <-- MUST change to decoded_path()
        for (route_method, route_path, handler) in &self.routes {
            if route_method == method && route_path.as_str() == path.as_str() {
                return handler.handle(ctx);
            }
        }
        NotFoundHandler.handle(ctx)
    }
}

struct NotFoundHandler;
impl Handler for NotFoundHandler {
    fn handle(&self, ctx: &mut Context) -> Result<()> {
        let body = b"Not Found".to_vec();
        let content_length = body.len().to_string();
        ctx.response = Response::new(404, "Not Found")
            .header("Content-Type", "text/plain")
            .header("Content-Length", &content_length)
            .header("Connection", "close")
            .body(body);
        Ok(())
    }
}

Add four public methods to the `impl Url` block after the existing `From<&str>` impl:

**path() -> &str**
Split raw_path on the first '?' and return everything before it. If no '?' is present, return
raw_path as a &str. Use `self.raw_path.find('?')` with a match.

**query() -> Option<&str>**
Return `self.raw_path.find('?').map(|idx| &self.raw_path[idx + 1..])`. This returns None when no
'?' is present, and Some("") when the path ends with '?'.

**decoded_path() -> Result<String>**
Use the byte-buffer approach (Pattern 2b from RESEARCH.md). Allocate a Vec<u8> with capacity
raw.len(). Iterate raw = self.path() as chars. On '%', consume the next two chars as hex digits
using the private hex_char_to_byte() helper, push the resulting byte. On any other char, push its
UTF-8 encoding via c.encode_utf8(&mut buf).as_bytes(). Convert the final Vec<u8> to String using
String::from_utf8(...).map_err(|e| e.to_string().into()). Do NOT call pct_decode() — use
hex_char_to_byte() directly to avoid the multi-byte-per-call complexity that pct_decode() has.

Return Err("invalid %-sequence: truncated".into()) if fewer than two chars follow '%'.
Return Err from hex_char_to_byte if a hex digit is invalid.

**is_safe() -> bool**
Call self.decoded_path(). On Err, return false. On Ok(decoded), split decoded on '/' and check that
no component equals "..". Return true if no component matches, false otherwise.
`!decoded.split('/').any(|component| component == "..")`

The full updated dispatch():
```rust
pub fn dispatch(&self, ctx: &mut Context) -> Result<()> {
    let decoded = match ctx.request.target.decoded_path() {
        Ok(d) => d,
        Err(_) => return NotFoundHandler.handle(ctx),
    };
    if decoded.split('/').any(|c| c == "..") {
        return NotFoundHandler.handle(ctx);
    }
    let method = &ctx.request.method;
    for (route_method, route_path, handler) in &self.routes {
        if route_method == method && route_path.as_str() == decoded.as_str() {
            return handler.handle(ctx);
        }
    }
    NotFoundHandler.handle(ctx)
}
```
