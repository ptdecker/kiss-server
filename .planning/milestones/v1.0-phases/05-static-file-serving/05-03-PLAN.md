EXACT parse_root() implementation to use (from RESEARCH.md Pattern 4):
```rust
fn parse_root() -> Result<std::path::PathBuf> {
    let args: Vec<String> = std::env::args().collect();
    let pos = args.iter().position(|a| a == "--root")
        .ok_or("--root <path> is required")?;
    let path_str = args.get(pos + 1)
        .ok_or("--root requires a path argument")?;
    let path = std::path::PathBuf::from(path_str);
    if !path.is_dir() {
        return Err(format!("--root '{}': not a directory or does not exist", path_str).into());
    }
    Ok(path)
}
```

Note: parse_root() validates is_dir() before passing to StaticFileHandler::new().
StaticFileHandler::new() then canonicalizes. Two layers of validation — both needed:
- is_dir() gives a user-friendly error message at startup
- canonicalize() in new() handles symlinks and relative paths correctly
