<objective>
Add a fallback handler slot to Router so StaticFileHandler can be registered as the catch-all for unmatched paths. This is the enabling infrastructure for Phase 5 file serving.

Purpose: The current Router always calls the built-in NotFoundHandler for unmatched paths. StaticFileHandler must receive those requests instead — without special-casing the dispatch loop, and without breaking the existing fallback-to-404 behavior when no fallback is registered.

Output: Router gains `fallback: Option<Box<dyn Handler>>` field, `set_fallback(mut self, handler) -> Self` builder, and an updated `dispatch()` that calls the fallback when set, or falls back to the built-in NotFoundHandler when not set.
</objective>
