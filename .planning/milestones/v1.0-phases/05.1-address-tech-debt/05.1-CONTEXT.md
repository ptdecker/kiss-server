## Implementation Decisions

### Dead API removal
- Remove `Url::is_safe()` from `src/url/mod.rs` — public but never called in production; dotdot logic is already inlined in `Router::dispatch`
- Remove `Url::query()` from `src/url/mod.rs` — public but never called in production
- Remove all associated tests for both methods from `url/mod.rs` test module
- `Router::dispatch` keeps its existing inline dotdot check (no refactor)

### peer_addr() fix
- `src/server/mod.rs:188` — Replace `stream.peer_addr()?` with `stream.peer_addr().unwrap_or_else(|_| ...)` (or similar non-propagating form) inside the `debug!` macro
- Goal: debug logging must not cause `handle_connection` to return `Err` and skip sending a response

### Stale #[allow(dead_code)] cleanup
- Remove `#[allow(dead_code)]` from `mime_type()` in `handlers/mod.rs` — function is used within the same file
- Remove `#[allow(dead_code)]` from `not_found()` in `handlers/mod.rs` — function is used within the same file
- Remove `#[allow(dead_code)]` from `StaticFileHandler` struct in `handlers/mod.rs` — public, registered in `main.rs`
- Remove `#[allow(dead_code)]` from `StaticFileHandler::new()` in `handlers/mod.rs` — public, called in `main.rs`
